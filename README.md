# Synchronous FIFO and Verification

This repository contains SystemVerilog code for a Synchronous FIFO
(first-inifirst-out) and it's verification environment. It is a
personal project to practice key concepts in Verilog, testbenches,
assertions and UVM.

## Contents

- fifo.sv: SystemVerilog code for async. FIFO
- tb: SystemVerilog code for testbench environment (no UVM)

This project is an ongoing project.
